Schriften fuer den AhrComp-Nachbau im Browserfenster (css/ahrcomp-mini.css)
==========================================================================

Dieselben Dateien wie auf ahrcomp.de, nur im Mini-Fenster benutzt.

    space-grotesk-500/700.woff2   Space Grotesk   SIL OFL 1.1 -> OFL-SpaceGrotesk.txt
    plex-sans-400/600.woff2       IBM Plex Sans   SIL OFL 1.1 -> OFL-IBMPlex.txt
    plex-mono-500.woff2           IBM Plex Mono   SIL OFL 1.1 -> OFL-IBMPlex.txt

Die Lizenzdateien muessen bei den Fonts bleiben.
